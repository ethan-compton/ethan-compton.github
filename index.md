Throughout my time at Southern New Hampshire University, I have learned a lot about computer science and what goes into developing software. When I first started the program, I had a pretty basic understanding of programming and wasn't familiar with many of the concepts I would eventually be working with. Over the past few years, I've gained experience with different programming languages, software development, algorithms, and databases. Some courses were more challenging than others, but each one helped me build on what I’d already learned. Looking back at where I started, I can see how much my understanding of computer science has improved and how much more comfortable I've become working through technical problems.

One of the biggest things I've learned is that software development involves a lot more than just writing code. There's planning, testing, debugging, and making sure everything works together the way it's supposed to. Throughout my coursework, I've had opportunities to work on different types of applications and figure out how to solve problems when something wasn't working correctly. I've also learned how important it is to keep code organized and understandable, especially when returning to an older project or making changes to existing functionality. Writing documentation and explaining my work through assignments and discussions has helped me get better at communicating technical information as well. While most of my experience has come from individual projects, I've gained a better understanding of why communication and collaboration are important when developing software.

My coursework has also introduced me to several areas of computer science that I didn't know much about when I started. Working with algorithms and data structures helped me understand how programs organize and process information, while database courses showed me how applications store, retrieve, and manage data. Through different assignments, I've learned about common vulnerabilities, input validation, and the importance of protecting information. Working on these projects gave me a chance to apply what I've learned throughout the program while also dealing with some of the challenges of returning to older code. I had to spend time understanding how each application worked before I could make improvements, which helped me see the importance of maintaining organized and readable code.

As I get closer to graduating, I'm excited to see where my computer science degree takes me. I'm still figuring out exactly what direction I want to go in, but application development is an area that I've particularly enjoyed learning about. I like the idea of creating software that people can actually use, and I'd like to continue improving my programming skills as I gain more experience. ## Algorithms and Data Structures — CS-300

### Project Overview

For my algorithms and data structures enhancement, I selected a C++ course advising application from my CS-300 course. The original program loaded course information from a CSV file and allowed users to view a complete course list or search for individual courses. It used a hash table to organize and retrieve course information, including course numbers, titles, and prerequisites.

For my enhancement, I added a prefix-based search feature that allows users to find courses without entering an exact course number. For example, entering "CS" displays a sorted list of courses that begin with those letters. I also made the search case-insensitive to make it easier to use. This enhancement gave me an opportunity to work with searching and sorting algorithms while maintaining the program's original functionality.

One of the challenges I encountered was getting familiar with the original code again and understanding how the hash table and search functions worked together. I also had to correct a file path issue that initially prevented the program from loading its course data. Working through these problems helped me better understand how different algorithms can work with the same data structure and reinforced the importance of testing changes to existing programs.

## Software Design and Engineering — CS-320

### Project Overview

For my software design and engineering enhancement, I chose a Java application from my CS-320 Software Testing, Automation, and Quality Assurance course. The original project involved managing contacts, tasks, and appointments through separate services. Each service handled its own information and included validation to prevent invalid data from being entered.

For my enhancement, I focused on improving how the different parts of the application worked together. I added a connection between contacts and appointments, allowing appointments to be associated with specific contacts. I also improved input validation and expanded the automated testing to make sure the new functionality worked correctly. The original project had 27 tests with one failure, while the enhanced version successfully passed all 32 tests. These changes helped make the application more organized, reliable, and easier to maintain.
